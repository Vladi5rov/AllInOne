# Air Quality Bulgaria - Full-Stack Application

Уеб приложение за проследяване и анализ на исторически данни за чистотата на въздуха (PM10 и PM2.5) за 28-те областни града в България през последните 12 месеца.

## 🛠 Технологичен стек
* **Frontend:** React.js (HTML5, CSS3, JavaScript)
* **Backend:** PHP 8+ (PDO, SQLite)
* **Външно API:** Open-Meteo Air Quality API (за реални исторически данни)
* **База данни:** SQLite (автоматично кеширане и архивиране)

---

## 🚀 Инструкции за локално стартиране (Development)

### 1. Бекенд (PHP & SQLite)
1. Клонирайте или поставете проекта в хостинг директорията на вашия локален сървър (напр. `htdocs/air-app` в XAMPP).
2. Уверете се, че PHP има активни разширения `pdo_sqlite` и `fileinfo`.
3. При първо заявка към `air-data.php`, скриптът автоматично ще създаде `air_quality.sqlite` базата и ще изтегли липсващите данни.

### 2. Фронтенд (React)
1. Отворете терминал в папката `frontend`:
   ```bash
   cd frontend
   
2. Инсталирайте зависимостите:
	npm install


3. Стартирайте DEV сървър:

	npm start

Приложението ще се отвори на http://localhost:3000.
